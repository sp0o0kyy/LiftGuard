# LiftGuard — журнал тренировок и аналитика для тренера

LiftGuard — информационно-аналитическая веб-система для мониторинга силовых показателей и субъективного самочувствия подопечных. Подопечный после тренировки вводит выполненное упражнение, вес, повторения, длительность, часы сна, самочувствие и заметки. Сервер сохраняет данные, рассчитывает базовые показатели и формирует ряды для графиков тренера.

Репозиторий проекта: https://github.com/sp0o0kyy/LiftGuard

## Текущий статус проекта

Проект развивается поэтапно. В репозитории находятся клиентская и серверная части, схема базы данных, миграции, авторизация, форма отправки тренировки, базовый кабинет тренера, расчётные показатели и графики. История коммитов отражает последовательную работу нескольких участников команды.

### Реализовано в базовой версии

- схема базы данных и миграции;
- регистрация, вход и выход;

- сессионная авторизация с cookie;
- серверная проверка доступа;
- страницы входа и регистрации;
- базовая форма отправки тренировки;

- серверная проверка диапазонов числовых полей;
- сохранение тренировки и расчёт тоннажа, подходов и повторений;
- базовый кабинет тренера;
- графики прогресса, сна и самочувствия, объёма нагрузки и веса;

## Требования к локальному запуску

Нужны Node.js 22, pnpm 10 и MariaDB. Настоящий файл `.env` с паролем базы не добавляется в GitHub. В репозитории находится только безопасный шаблон `.env.example`.

### Windows Command Prompt

```bat
copy .env.example .env
```

Откройте `.env` и укажите локальное подключение к MariaDB, например:

```env
NODE_ENV=development
PORT=3000
DATABASE_URL=mysql://liftguard:LIFTGUARD_PASSWORD@127.0.0.1:3306/liftguard
```

Затем выполните:

```bat
corepack enable
corepack prepare pnpm@10.18.0 --activate
pnpm install --frozen-lockfile
pnpm db:migrate
pnpm seed
set NODE_ENV=development&& pnpm exec tsx watch server/_core/index.ts
```

Откройте в браузере `http://localhost:3000/login`.

### Linux/macOS

```bash
corepack enable
corepack prepare pnpm@10.18.0 --activate
pnpm install --frozen-lockfile
cp .env.example .env
pnpm db:migrate
pnpm seed
pnpm dev
```

Откройте `http://localhost:3000/login`.

## Технологии

Основной язык — TypeScript. Frontend написан на React 19 и Vite, стилизован Tailwind CSS. Backend работает на Node.js, Express и tRPC. Для проверки данных используется Zod. Для базы используется MariaDB через Drizzle ORM и драйвер `mysql2`. Графики построены на Recharts, автоматические тесты — на Vitest.

## Ограничения текущей версии

В текущей базовой версии нет платежей, видеосвязи, питания, мобильных приложений, интеграций с фитнес-браслетами, push-уведомлений и публичного запуска. Программа не ставит медицинские диагнозы: она сохраняет введённые данные, выполняет прозрачные арифметические расчёты и показывает динамику.
