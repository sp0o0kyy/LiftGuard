# LiftGuard — журнал тренировок и аналитика для тренера

LiftGuard — учебная информационно-аналитическая система для мониторинга силовых показателей и субъективного самочувствия подопечных. Ученик после тренировки сохраняет выполненную программу с упражнениями, весами, подходами и повторениями, часы сна, самочувствие, вес тела и заметки. Тренер видит историю связанных записей, графики, числовые сравнения и может отвечать на комментарии к конкретной тренировке.

Основные расчёты выполняются алгоритмами TypeScript: считаются тоннаж, подходы, повторения, средний сон, среднее самочувствие, изменение веса, разница с предыдущей тренировкой и рекорды упражнений.
## Возможности

- отдельные роли и кабинеты тренера и ученика;
- привязка ученика к тренеру по коду приглашения;
- журнал тренировки с самочувствием, сном, весом и заметками;
- повторное использование ранее заполненной программы;
- автоматический подсчёт тоннажа, подходов и повторений;
- сравнение текущих весов и самочувствия с предыдущей тренировкой;
- рекорды по упражнениям;
- дашборд тренера с графиками силовых, сна, самочувствия, объёма и веса тела;
- двусторонние комментарии к тренировке и индикатор непрочитанных сообщений;
- антропометрия: рост, стартовый, текущий и целевой вес;
- адаптивный интерфейс для смартфона и компьютера;

## Быстрый локальный запуск

Нужны Node.js 22, pnpm 10 и MySQL/MariaDB.

```bash
git clone https://github.com/ВАШ_ЛОГИН/liftguard.git
cd liftguard
corepack enable
corepack prepare pnpm@10.18.0 --activate
pnpm install --frozen-lockfile
cp .env.example .env
# укажите DATABASE_URL и JWT_SECRET в .env
pnpm db:migrate
pnpm seed
pnpm dev
```

Откройте http://localhost:3000.

## Проверка проекта

```bash
pnpm check
pnpm test
pnpm build
```

Эти команды проверяют TypeScript, автоматические серверные тесты и production-сборку.

## Передача данных тренеру

В серверной версии после отправки тренировки запись сохраняется в MariaDB и становится видна привязанному тренеру в приложении. Отдельные email, Telegram или push-уведомления пока не отправляются; для этого потребуется отдельная интеграция с SMTP или Telegram Bot API.

## Технологии

Основной язык — TypeScript. Frontend написан на React 19 и Vite, стилизован Tailwind CSS. Backend работает на Node.js, Express и tRPC. Для базы используется MariaDB через Drizzle ORM. Графики построены на Recharts.
