# LiftGuard — журнал тренировок и аналитика для тренера

LiftGuard — информационно-аналитическая система для мониторинга силовых показателей и субъективного самочувствия подопечных. Ученик после тренировки вводит выполненную программу с упражнениями, весами, подходами и повторениями, часы сна и самочувствие. Тренер получает сохранённые записи и может использовать их для анализа динамики.

## Текущий статус проекта

Репозиторий ведётся поэтапно. На текущем этапе в GitHub загружены первые четыре коммита: каркас проекта, документация, схема базы данных и серверная авторизация. Следующие коммиты формируют базовую версию для промежуточной демонстрации.

### Реализовано в базовой версии

- каркас клиентской и серверной частей;
- схема базы данных и миграция;
- регистрация, вход и выход;
- роли тренера и подопечного;
- сессионная авторизация и проверка доступа;
- страницы входа и регистрации;
- базовая оболочка интерфейса;
- форма ввода тренировки;
- ввод даты, длительности, сна, самочувствия, упражнений, веса, подходов и повторений;
- сохранение записи и базовая история тренировок;
- базовые расчётные показатели и графики.

### Предстоит реализовать в полной версии

- расширенная привязка подопечного к тренеру по коду приглашения;
- расширенный профиль и карточка подопечного;
- дополнительные антропометрические данные;
- сравнение текущих результатов с предыдущими тренировками;
- расширенный дашборд тренера;
- подробные комментарии к тренировкам и индикатор непрочитанных сообщений;
- расширенные рекорды, графики и аналитические представления;
- проверка трёх заранее подготовленных пользовательских сценариев и подготовка версии к следующей защите.

## Быстрый локальный запуск

Нужны Node.js 22, pnpm 10 и MySQL/MariaDB.

```bash
git clone https://github.com/sp0o0kyy/LiftGuard.git
cd LiftGuard
corepack enable
corepack prepare pnpm@10.18.0 --activate
pnpm install --frozen-lockfile
cp .env.example .env
# укажите DATABASE_URL и JWT_SECRET в .env
pnpm db:migrate
pnpm seed
pnpm dev
```

Откройте `http://localhost:3000`.

## Проверка проекта

```bash
pnpm check
pnpm test
pnpm build
```

Эти команды проверяют TypeScript, автоматические серверные тесты и production-сборку.

## Технологии

Основной язык — TypeScript. Frontend написан на React 19 и Vite, стилизован Tailwind CSS. Backend работает на Node.js, Express и tRPC. Для базы используется MariaDB через Drizzle ORM. Графики построены на Recharts.
